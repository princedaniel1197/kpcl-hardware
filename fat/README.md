# fat — test plan and records

The test report is the deliverable that persuades. The software is what makes the
report true.

- `records/` — one record per stage, written when that stage's test is actually run.
  A record states what was run, on what, with what result. A stage whose test has
  not been run gets a record saying so, not an absence and not an optimistic entry.
- The Inspection and Test Plan, the FAT procedure and the automated runner are
  Stage 14. They are not written ahead of the evidence they organise.

Nothing in this directory may claim a behaviour that has not been measured.
